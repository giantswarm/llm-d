# What the llm-d-slim/ variant of llm-d-cuda leaves out (scripts/relayer.py
# plan --drop): one glob per line, matched against the path without the
# leading slash; an entry goes when its path or an ancestor's matches.
#
# The slim variant serves the GPUs of the curated AWS families, Ampere and Ada
# (A10G sm86, L4 and L40S sm89). What goes below is either built for one
# Hopper or Blackwell architecture only, or a CUDA 12 build in a CUDA 13
# image; vLLM and FlashInfer reach none of it on those GPUs, and every import
# of it is optional. Hopper and Blackwell nodes keep the full image.

# probe NVIDIA's artifactory over the network before choosing a backend.
